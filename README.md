# Overtourism & Airbnb Data Analysis

This project analyzes the relationship between Airbnb growth, tourism, and housing markets across major cities:
- Barcelona
- Amsterdam
- Lisbon
- New York

## Languages/Libraries Used
- Python
- Pandas
- Matplotlib / Seaborn
- NumPy / SciPy

## How to Run
1. Install dependencies:
pip install -r requirements.txt
2. Run the program:
python generate_graphs.py
3. Figures will be saved in:
figures/

## Data
Due to file size limits, raw datasets are not included in this repository. Sources for data can be found in the appendix of the analysis (docs/overtourism_analysis.pdf) Please add them accordingly into the data/ files if being used.
